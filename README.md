# Gonzalo Lobo · Portfolio

Portfolio personal en Next.js (App Router) + TypeScript, en español (`/es`) e inglés (`/en`).

- Textos de todo el sitio: `src/content.ts`
- Estilos: `src/app/globals.css`
- CV descargables: `public/cv/`
- Capturas de proyectos: `public/projects/`

```bash
pnpm install
pnpm dev     # http://localhost:3000
pnpm build
```

En Vercel, el proyecto debe tener el framework "Next.js" (Settings → Build & Deployment).
